Kleborate-viz is a web app to visualise the output of [Kleborate](https://github.com/klebgenomics/Kleborate) - a genotyping tool for _Klebsiella pneumoniae_ and its related species complex. Kleborate and Kleborate-viz are described in [this paper](https://doi.org/10.1038/s41467-021-24448-3).

Start by visiting the Kleborate-viz [app online](https://klebsiella.shinyapps.io/Kleborate-viz/) or reading more on the
[wiki](https://github.com/klebgenomics/Kleborate-viz/wiki). 

You can also run the app locally on your own computer via RStudio. Just clone this repository, open global.R in RStudio, and click 'Run App'.
